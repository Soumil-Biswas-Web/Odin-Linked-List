# Odin-Linked-List

A simple excercise to create a Linked List Class to store values.

The class (Created in index.js) has the following classes/functions.

# Class node()

A class created for each individual node in the Linked List. For exclusive use by the LinkedList() class. Contatins a `value` and `nextNOde` attributes.

# Class LinkedList()

Use `const x = new LinkedList();` to create a new Linked List. The name of the Linked List is 'x'.

The LinkedList() class has the following available functions:

## append()

Use x.append(value) to add a new value at the end of the linked list.

## prepend()

Use x.prepend(value) to add a new value at the begining of the linked list.

## size()

Use x.size() to check the number of items in the linked list.

## head()

Use x.head() to get the first value from the linked list.

## tail()

Use x.tail() to check the the last value in the linked list.

## at()

Use x.at(index) to find the value at the given index in the linked list.

## pop()

Use x.pop() to remove the last value stored in the linked list.

## contains()

Use x.contains(value) to check if the given value exists in the linked list.

## find()

Use x.find(value) to find the index of a given value in the linked list.

## toString()

use x.toString() to return the values in the linked list as a string.
